# Student Admission System

A web app to register students and manage their subjects, hostel bed and marks.

**Stack:** FastAPI, SQLAlchemy, SQL Server, HTML/JavaScript (Bootstrap)

## Features
- Add, edit, delete and search students
- Subjects per student (four default subjects are assigned automatically)
- One hostel, room and bed per student
- Marks per subject and year, with Pass/Fail calculated by the database
- Details view: profile, hostel, subjects and marks in one place

## Design notes
- **IDs are generated by SQL Server (`IDENTITY`)**, not by the application, so simultaneous saves always get different IDs. The ID is shown only after saving.
- **UNIQUE constraints** on email, phone, and name + date of birth reject duplicates in the database itself. A bed can never be given to two students.
- A new student and their default subjects are saved in one transaction.

## Run it
1. **Database:** in SSMS, run the scripts in `Database/` in order: `01`, `02`, `04`, `05`, `06` (`03` is optional demo queries).
2. **Backend:**
   ```
   cd Backend
   pip install -r requirements.txt
   python -m uvicorn main:app --reload --port 8001
   ```
   The connection string is in `Backend/database.py` (SQL Server on localhost, Windows authentication, ODBC Driver 18).
3. **Frontend:** open `Frontend/index.html` (for example with VS Code Live Server).
